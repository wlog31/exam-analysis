# examAnalysis

엑셀 기반 성적 분석 웹앱입니다.

## 1) 개발 실행

```bash
npm install
npm run dev
```

## 2) 초기 설정 및 데이터 로드

1. 홈 화면에서 `문항정보표` 엑셀 파일(`.xlsx`, `.xls`)을 선택합니다.
2. `정오표` 엑셀 파일을 선택합니다. 여러 학급을 함께 분석하려면 파일 선택 창에서 여러 정오표를 한 번에 고르거나 업로드 박스에 함께 드래그합니다.
3. `데이터 불러오기`를 누릅니다.

참고:
- 시트 이름은 파일 선택 시 자동으로 로드됩니다.
- 데이터 로드가 완료되면 대시보드/문항분석/학생목록 화면으로 이동할 수 있습니다.
- 분석이 완료되면 마지막 분석 결과가 브라우저 저장소에 보관되어, 프로그램을 다시 실행해도 바로 확인할 수 있습니다.

## 3) 학생목록 출력 기능

학생목록 화면 우측 상단에는 2개의 출력 버튼이 있습니다.

- `개별 분석 일괄 출력`
- `인쇄`

기능 설명:
- `개별 분석 일괄 출력`: 전체 학생의 개별 분석 문서를 페이지 단위로 생성해 한 번에 인쇄합니다.
- `인쇄`: 현재 학생목록 화면 자체를 인쇄합니다.

## 4) 엑셀 파일 구조

샘플 파일: `data/샘플_문항정보표.xlsx`, `data/샘플_정오표.xlsx`

문항정보표 파일과 정오표 파일이 필요합니다. 정오표는 여러 학급 파일을 동시에 올릴 수 있습니다.

---

### 파일 1: 문항정보표

문항별 메타 정보(내용영역, 성취기준, 난이도, 배점, 정답)를 담습니다.

과목명, 학년도, 학기, 학년, 고사 차수, 고사일자, 선택형/서답형 총점은 파일 상단의 메타 정보에서 자동으로 추출합니다.

| 행 | 내용 |
|----|------|
| 1~6 | 시험 메타 정보 (과목, 학년, 학기, 차수, 일시, 총점 배점) |
| 7 | 섹션 제목 (`선택형 문항` 또는 `서답형 문항`) |
| 8~9 | 컬럼 헤더 (`문항번호 / 내용영역 / 성취기준 / 난이도 / 배점 / 정답`) |
| 10~ | 문항 데이터 행 (섹션별 반복) |

**문항 데이터 행 컬럼 구조 (선택형/서답형 공통):**

```
A열(번호) | B열(내용영역) | C열(성취기준) | D(어려움) | E(보통) | F(쉬움) | G(배점) | H(정답)
```

- 난이도는 해당 열에 `○` 표시
- 서답형 정답 칸은 `별도` 로 입력 (채점 기준서 별도)

**섹션 구분 방법:**
- `선택형 문항` 텍스트가 있는 행 → 이후 문항은 선택형으로 파싱
- `단답형 문항` 텍스트가 있는 행 → 이후 문항은 단답형 타입으로 저장
- `서술형 문항` 텍스트가 있는 행 → 이후 문항은 서술형 타입으로 저장
- `서답형 문항` 텍스트가 있는 행 → 단답형·서술형 통합 처리

> **참고:** 단답형·서술형을 **점수 기준으로 분리 분석**하려면 정오표도 분리 모드 구조여야 합니다. 문항정보표의 섹션 라벨만으로는 점수 분리가 트리거되지 않습니다.

---

### 파일 2: 정오표

학생별 선택형 응답과 점수를 담습니다.

여러 학급의 정오표를 동시에 올리면 학생 데이터가 하나로 합쳐져 통합 분석됩니다. 이때 파일 간 선택형 정답키, 배점, 서답형 통합/분리 구조는 같아야 합니다.

| 행 | 내용 |
|----|------|
| 1~2 | 날짜, 제목 |
| 3 | 학년도/학기/차수 정보 **또는** 단답형·서술형 섹션 레이블 (분리 모드) |
| 4 | 컬럼 헤더 (`반/번호 / 번호 / 이름 / 1 / 2 / … / 선택형 / 서답형 / 기타점수 / 과목총점`) |
| 5 | 정답 행 (`정답` 레이블) |
| 6 | 배점 행 (`배점` 레이블) |
| 7~ | 학생 데이터 행 |

**학생 데이터 행 컬럼 구조 (통합 모드):**

```
[학번] | [반/번호] | [이름] | [선택형 응답 × N문항] | [선택형점수] | [서답형점수] | [기타점수] | [과목총점]
```

선택형 문항 수(N)는 파일마다 다를 수 있으며, 열 위치는 고정되지 않습니다.  
점수 열(선택형점수·서답형점수·기타점수·과목총점)은 항상 선택형 응답 블록 바로 오른쪽에 순서대로 위치합니다.

- 선택형 응답: 정답이면 `.`, 오답이면 해당 번호
- 선택형점수: 자동 합산된 선택형 총점
- 서답형점수: 선생님이 직접 입력한 주관식 총점 (단답형·서술형 합산)
- 기타점수: 추가 부여 점수
- 과목총점: 최종 총점

---

### 서답형 분리/통합 모드

| 모드 | 정오표 3행 | 분석 방식 |
|------|-----------|----------|
| **통합** | 학년도/학기 정보 (단답형·서술형 미구분) | 서답형점수 열을 통합 점수로 처리 |
| **분리** | 과목총점 열 오른쪽부터 `단답형`·`서술형` 레이블이 모두 포함 | 4행에 각 섹션의 문항 번호, 해당 컬럼 범위의 점수를 각각 합산 |

**분리 모드 컬럼 구조:**

```
[학번] | … | [과목총점] | [단답형 q1점수] | [단답형 q2점수] | … | [서술형 q1점수] | [서술형 q2점수] | …
                           ↑ 3행: 단답형                           ↑ 3행: 서술형
                           ↑ 4행: 1, 2, ...                        ↑ 4행: 1, 2, ...
```

통합 모드에서는 대시보드에 서답형 합계만 표시되며, 분리 모드에서는 단답형·서술형 평균이 별도 표시됩니다.

---

### 분석 연결 구조

```
문항정보표              정오표
────────────           ────────────────────────
문항번호, 유형          ← 선택형 문항 번호로 응답 매칭
내용영역, 성취기준      → 내용영역별 정답률 집계
난이도                 → 난이도별 정답률 그래프
배점                   → 문항별 평균 획득점
정답                   ← 정오표 정답 행으로 보완 가능
                       선택형 점수  → 선택형 평균
                       서답형 점수  → 서답형 평균
                       과목총점     → 전체 통계, 학생 순위
```

## 5) 배포

### GitHub Pages 수동 배포

```bash
npm run deploy
```

```bash
npm run desktop:dev
```

빌드:

```bash
npm run desktop:build
```

빌드 결과:
- `release/ExamAnalysis-win32-x64/ExamAnalysis.exe`
